# Doubt Clarification System - Frontend & Backend

## Setup Instructions

### Backend (Flask API)
```bash
cd academic_system/api
pip install -r requirements.txt
python app.py
```
Backend runs on: http://localhost:5000

### Frontend (React)
```bash
cd frontend
npm install
npm start
```
Frontend runs on: http://localhost:3000

## Features
- ✅ Student Chat Interface
- ✅ Real-time question validation (Layer 1 + Layer 2)
- ✅ Status badges (VALID/WARNING/REJECTED/OUT_OF_SYLLABUS)
- ✅ Feedback buttons
- ⏳ Admin Dashboard (Phase 2)
- ⏳ Answer Generation (Phase 2)
